# 流程详解

> 九个环节各自的**做什么 / 预期 / 产物**，以及文件约定、提示词索引。
> 只想跑起来看 [README](../README.md)；只想装环境看 [安装与配置](安装与配置.md)。

## 全流程

```
素材 → 匀素材 → 剪辑 → 纠正字幕生成标题 → 生成篇名 → 导出 → 拼接 → 命名 → 台账
 人      程序     人    程序+人  人    程序    程序    程序    程序+模型
```

默认规则（`conf/默认规则.yaml`，建批次时可改，改完写进 `game.yaml` 定稿）：

| 项                 | 默认                                   |
| ------------------ | -------------------------------------- |
| 每个合集的素材目标 | 2 小时                                 |
| 每个合集切成几集   | 20 集                                  |
| 每集正文时长       | 6 分钟（不含片头片尾）                 |
| 台账里的片头额度   | 每集 30 秒（20 集 = 600 秒，甲方口径） |
| 导出               | 1080P / 30fps / H.264 / mp4            |

### ① 素材　【人工】

**做什么**：OBS 录屏，放进 `合集/合集X/素材/`。一个合集可以有多个文件。

**预期**：总时长 ≥ 2 小时。差太多要重录；多了走下一步匀掉。

### ② 匀素材　【程序检查，人决策】

```powershell
vedio balance --game 我的世界 --batch 2026-12            # 只查
vedio balance --from 合集一 --to 合集二 --apply          # 真切
```

**做什么**：算每个合集的素材总时长，报「超出多少」。**只报事实，不给建议。**

**预期**：每个合集落在「目标 ±3 秒」内。超出的部分切给下一个合集
（关键帧处切开、`-c copy`、不重编码，画质无损）。

**为什么排在最前**：素材多了 3 分钟，剪辑时会多切出一两段"废篇"，
一路污染到台账（多出几行、甲方看到不存在的集）。

### ③ 剪辑　【人工】

**做什么**：在剪映里剪 —— 删掉无效片段（切屏幕、卡顿、走神），需要的话加背景/边框；
然后**从剪映导出 `.txt` 和 `.srt`**，放到 `合集/合集X/剪辑/`。

**预期**：`剪辑/` 里有一个 `*.txt`（字幕文本）和一个 `*.srt`（带时间轴）。

**为什么必须导出这两个文件**：后面的字幕纠错、时间轴对齐都从它们开始；
没有它们，程序不知道视频里说了什么、第几秒说的。

### ④ 字幕　【程序 + 人工审查】

```powershell
vedio subtitle --game 我的世界 --batch 2026-12 --collections 合集一 --quiet
```

三步串行，前一步失败就停：

| 步        | 做什么                                                                        | 产物              |
| --------- | ----------------------------------------------------------------------------- | ----------------- |
| `number`  | 给 txt 每行加行号（模型纠错时要靠它定位）                                     | `*_ordered.txt`   |
| `correct` | **agent 六个节点**：解析主题 → 查知识库 → 缺则构建 → 加行号 → 纠正 → 生成标题 | `corrected.txt`   |
| `patch`   | 把纠正结果按行号写回 srt，**逐块替换时间轴内的文本**                          | `*_corrected.srt` |

**预期**：`剪辑/` 里有 `*_corrected.srt`（UTF-8 无 BOM + CRLF，和剪映自己导出的一致）
和 `corrected.txt`（改了哪些、为什么）。

**然后人工**：把 `*_corrected.srt` 导回剪映，**逐集审一遍**。审完才能往下走。

> 这一步是这个项目里唯一"机器可能改错"的地方 —— 模型会把"猪灵"写成"朱灵"。
> 所以字幕审查是**人的责任**，程序不替你做这个决定。

### ⑤ 篇名　【模型提候选，人拍板】

```powershell
vedio series --suggest "合集一,合集二"     # 模型根据各集标题提一个
vedio series --groups "合集一,合集二=罗盘寻迹下界行"   # 人确认后写入
```

**做什么**：决定这一组合集的「篇名」，以及它们在文件名叫「-上篇 / -下篇」。

**预期**：`标题.md` 每节变成 `#### 合集一:罗盘寻迹下界行-上篇`。

**为什么必须在导出之前**：台账的第一列、成片的文件名都要用它。
等导完拼完才发现没篇名，整轮白跑 —— 所以 `export` 和 `ledger` 都会拦住（`title_missing`）。

### ⑥ 导出　【程序，点剪映】

```powershell
vedio export --game 我的世界 --batch 2026-12 --collections 合集一,合集二 --quiet
```

**做什么**（按顺序，每步都有超时和重试）：

1. 检查剪映开着（没开直接返回 `jianying_not_running`）
2. 检查篇名已定（没有返回 `title_missing`）
3. 检查空间：**导出 + 后面拼接要用的空间一起算**，不够直接拒绝（`disk_full`）
4. 逐个合集：进草稿 → 设导出目录 → 点导出 → 等文件写完 → 用 ffprobe 核对分辨率和帧率

**预期**：`剪辑/` 里有成片 `*.mp4`（每个合集一个长片）。

**已知限制**：剪映 6.0.1 的分辨率/帧率下拉在 UIA 里看不见，程序设不了 ——
所以只能「用剪映当前的设置，导出后核对」。配置里 `export.apply_params: false` 就是关掉尝试。

### ⑦ 拼接　【程序，跑 ffmpeg】

```powershell
vedio splice --game 我的世界 --batch 2026-12 --collections 合集一,合集二 --quiet
```

**做什么**：

1. 校验片头片尾（没登记/文件不存在 → `template_missing`，不猜、不用别的代替）
2. 估空间（不够 → `disk_full`，**一个字节都不写**）
3. 按集数切分长片（`-c copy`，不重编码）
4. 每段拼成「片头 + 正片 + 片尾」
5. 帧率不一致时（片头 25fps vs 正片 30fps）先转一次缓存，之后走 copy
6. copy 拼完**验一次时长**（对不上就改用重编码，因为 `-c copy` 可能成功但时间戳是坏的）

**预期**：`成片/合集X-01.mp4 … -20.mp4`。

### ⑧ 命名　【程序】

```powershell
vedio rename --game 我的世界 --batch 2026-12 --collections 合集一,合集二
```

**做什么**：按 `标题.md` 的标题 + `game.yaml` 的命名模板改文件名。

**预期**：`波波之我的世界 罗盘寻迹下界行-上篇 第三集 自然指南针传送.mp4`。

**注意**：成片比标题多时（素材长了），多出来的**改不了名**，程序会如实报
「另有 N 个没有对应标题」—— 不静默跳过。

### ⑨ 台账　【程序 + 模型】

```powershell
vedio ledger --game 我的世界 --batch 2026-12 --collections 合集一,合集二
```

**做什么**：

1. **以标题为准**一行一集（废篇不入表）
2. 片头时长按**合同**算：集数 × 30 秒 = 600 秒（不是片头文件的实际长度）
3. 模型写「内容介绍」（20~40 汉字，以主播名开头）和「关键字」（4~6 个，跨合集不重复）
4. 格式交给外部脚本（`paths.excel_generator`，**相对仓库根目录**）：汇总行、合并单元格、配色

**预期**：`{批次}/26年波波12月第一批片单.xlsx`，可直接交付。

## 文件约定

**机器的配置**（不进 git）：

| 文件              | 放什么                                              |
| ----------------- | --------------------------------------------------- |
| `conf/本机.yaml`  | 工作区在哪、ffmpeg 在哪、台账输出目录、片单生成脚本 |
| `conf/agent.yaml` | DeepSeek 的 api_key / 模型名 / max_tokens           |

**项目的规则**（进 git）：

| 文件                            | 放什么                                             |
| ------------------------------- | -------------------------------------------------- |
| `conf/默认规则.yaml`            | 所有批次的默认值（时长、集数、导出参数、命名模板） |
| `conf/游戏规则/{游戏}.yaml`     | 某个游戏的覆盖项                                   |
| `conf/知识库/{游戏}/{主题}.md`  | 字幕纠错用的领域知识（术语、常见错听）             |
| `src/deal_video_agent/prompts/` | **所有提示词**（见下节）                           |

**每个批次**（在 `workspace.root` 下）：

| 文件/目录          | 放什么                                     | 谁写                                 |
| ------------------ | ------------------------------------------ | ------------------------------------ |
| `game.yaml`        | 本批次完整配置，建完定稿                   | `init`                               |
| `进度.md`          | 每个合集每一步打了没打勾                   | 程序打勾，人可手改                   |
| `标题.md`          | 公共前缀 + 每合集一节（副标题 + 各集标题） | `subtitle` 写标题，`series` 写副标题 |
| `合集清单.yaml`    | 草稿名、片头片尾映射                       | 程序写，人核对                       |
| `台账记录.json`    | 已出过的内容介绍/关键字（下次生成时去重）  | `ledger`                             |
| `log/`             | 每次调用的完整日志                         | 程序                                 |
| `合集/合集X/素材/` | OBS 原始录屏                               | 人                                   |
| `合集/合集X/剪辑/` | 草稿、导出的 txt/srt、纠正结果、长片       | 人 + 程序                            |
| `合集/合集X/成片/` | 最终 20 集                                 | `splice`、`rename`                   |

## 提示词在哪

全部在 `src/deal_video_agent/prompts/`，**一处改，不用动代码**。
支持 `prompts/games/{游戏}.yaml` 按游戏覆写（同名键整条替换）。

| 环节            | 键                    | 输入                                 | 输出              |
| --------------- | --------------------- | ------------------------------------ | ----------------- |
| 字幕 · 建知识库 | `knowledge_building`  | 主题名                               | 一份知识库 md     |
| 字幕 · 纠错     | `subtitle_correction` | 带行号字幕 + 知识库                  | 纠正后的文本      |
| 字幕 · 起标题   | `title_generation`    | 纠正后的字幕                         | 每集一条标题      |
| 篇名            | `series_suggest`      | 各集标题                             | 一个篇名候选      |
| 台账文案        | `ledger_copy`         | 各集标题 + 上一篇的简介 + 已用关键词 | 内容介绍 + 关键字 |

前三个在 `prompts/subtitle_correction.yaml`，后两个在 `prompts/editorial.yaml`。
