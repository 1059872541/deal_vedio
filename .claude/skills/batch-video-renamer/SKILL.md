# 🎬 视频批量重命名工具

> 即使是第一次使用也能轻松完成视频重命名

---

## 📋 第一步：选择场景

请告诉我你要处理的情况：

| 选项 | 场景 | 说明 |
|------|------|------|
| **A** | 单个合集 | 只有一个文件夹的视频需要重命名 |
| **B** | 多个合集 | 有多个文件夹（如合集一、合集二、合集三）需要一起重命名 |

---

## 📋 第二步：提供信息

### 场景A：单个合集

请提供以下信息：

```
1. 视频文件夹路径：__________
2. 公共前缀：__________
   （示例：波波之我的世界）
3. 合集前缀：__________
   （示例：制作传送门）
4. 视频标题列表：__________
   （用逗号分隔，每个标题对应一集视频）
```

### 场景B：多个合集

请提供以下信息：

```
1. 公共前缀：__________
   （示例：波波之我的世界）

2. 合集信息（每个合集一行）：
   - 合集一路径：__________
     合集一前缀：__________
     标题列表：__________

   - 合集二路径：__________
     合集二前缀：__________
     标题列表：__________

   - 合集三路径：__________
     合集三前缀：__________
     标题列表：__________
   （以此类推，数量不限）
```

---

## 📋 第三步：标题格式说明

### 如何提供标题

你可以用以下方式提供标题（AI会自动处理）：

- **逗号分隔**：标题1,标题2,标题3
- **空格分隔**：标题1 标题2 标题3
- **换行分隔**：每行一个标题
- **分号分隔**：标题1;标题2;标题3
- **中文标点**：标题1，标题2；标题3

AI会自动统一转换为标准格式。

### 标题数量要求

- 标题数量必须等于视频文件数量
- AI会帮你检查并提示

## ❓ 常见问题

### Q1: 我不知道视频文件在哪里
A: 打开文件夹，找到类似 `MC-合集-1_c1.mp4` 的文件，告诉我文件夹路径即可

### Q2: 标题要写多少个
A: 有多少个视频文件就写多少个标题，AI会帮你检查数量是否匹配

### Q3: 前缀是什么
A: 前缀就是视频名称开头的固定部分，例如：
   - `波波之我的世界 制作传送门 第一集 落入积雪中.mp4`
   - 「波波之我的世界 制作传送门」就是前缀

### Q4: 可以只重命名一部分吗
A: 可以，标题数量与文件数量一致即可

### Q5: 担心操作失误怎么办
A: 可以先让AI只做预览确认，不实际执行

## 🔧 技术参数（可选了解）

| 参数 | 说明 | 示例 |
|------|------|------|
| `--pattern` | 文件匹配模式 | `MC-合集-*_c*.mp4` |
| `--prefix` | 完整前缀 | `波波之我的世界 制作传送门` |
| `--titles` | 标题列表 | `标题1,标题2,标题3` |
| `--execute` | 执行标记 | 添加此参数才真正执行 |
| `--no-backup` | 不创建备份 | 加快执行速度 |

### 命令示例

```bash
# 预览
python rename_videos.py --pattern "MC-合集-*_c*.mp4" --prefix "前缀" --titles "标题1,标题2"

# 执行 (AI方式)
echo "yes" | python rename_videos.py --pattern "MC-合集-*_c*.mp4" --prefix "前缀" --titles "标题1,标题2" --execute --no-backup
```
