### 1. 文件处理问题
#### 问题 F-001: 文件名包含中文导致 bash 乱码
- **发现日期**: 2025-03-08
- **严重程度**: 高
- **影响范围**: Windows 系统下的 bash 环境
- **问题现象**: 
  ```
  $ ls -1 *.mp4
  MC-�\220\210�\233\2061_c1.mp4
  ```
- **根本原因**: 
  1. 终端编码与文件系统编码不匹配
  2. bash 对 UTF-8 中文支持不完整
  3. Windows 路径分隔符和编码问题
- **解决方案**:
  1. 使用 Python 脚本替代 bash 命令
  2. 强制使用 UTF-8 编码处理所有字符串
  3. 使用 `pathlib` 库进行跨平台文件操作
- **修复版本**: v1.0
- **状态**: ✅ 已解决

#### 问题 F-002: 文件排序不符合数字顺序（c10 排在 c2 前）
- **发现日期**: 2025-03-08
- **严重程度**: 中
- **影响范围**: 所有按数字编号的文件
- **问题现象**:
  ```
  默认排序: c1, c10, c11, c2, c3, ...
  期望排序: c1, c2, c3, ..., c10, c11
  ```
- **根本原因**: 字符串字典序排序 vs 数字自然排序
- **解决方案**:
  1. 使用自然排序算法 `natural_sort_key()`
  2. 在 Python 中实现 `sort_files_naturally()` 方法
  3. 支持复杂模式如 `c1`, `c2a`, `c2b`, `c10`
- **代码实现**:
  ```python
  def natural_sort_key(self, filename: str) -> List:
      def convert(text):
          return int(text) if text.isdigit() else text.lower()
      return [convert(c) for c in re.split(r'(\d+)', filename)]
  ```
- **修复版本**: v1.0
- **状态**: ✅ 已解决

### 2. 内容处理问题
#### 问题 C-001: 标题与前缀内容重复
- **发现日期**: 2025-03-08
- **严重程度**: 低
- **影响范围**: 标题包含前缀关键词的情况
- **问题现象**:
  ```
  前缀: "波波之我的世界 培养制图师-上篇"
  标题: "村庄复兴 培养制图师-上篇"
  结果: "波波之我的世界 培养制图师-上篇 第二十集 村庄复兴 培养制图师-上篇.mp4"
  ```
- **根本原因**: 用户提供的标题可能包含前缀中的关键词
- **解决方案**:
  1. 实现 `remove_duplicate_text()` 方法
  2. 基于词语级别进行重复检测
  3. 保留必要的内容，避免过度删除
- **算法逻辑**:
  1. 将前缀拆分为词语集合
  2. 检查标题中的每个词语
  3. 移除出现在前缀集合中的词语
  4. 保留至少一个词语（避免空标题）
- **修复版本**: v1.0
- **状态**: ✅ 已解决

#### 问题 C-002: 中文数字转换限制（仅支持1-20）

# 自然排序实现
def natural_sort_key(filename: str) -> List:
    def convert(text):
        return int(text) if text.isdigit() else text.lower()
    return [convert(c) for c in re.split(r'(\d+)', filename)]

# 重复文本移除
def remove_duplicate_text(prefix: str, title: str) -> str:
    prefix_words = set(prefix.split())
    title_words = title.split()
    filtered_words = [w for w in title_words if w not in prefix_words]
    result = ' '.join(filtered_words).strip()
    return result if result else title

# 安全文件操作
def safe_rename(old_path, new_path):
    if Path(new_path).exists():
        raise FileExistsError(f"目标文件已存在: {new_path}")
    Path(old_path).rename(new_path)
