# 工作流说明

## 使用流程

### 第一步：运行扫描脚本

```bash
python scan_videos.py "D:\VedioRecords\工作区\我的世界_202604\合集" "合集六,合集七,合集八,合集九,合集十"
```

### 第二步：获取结果

脚本会输出：
1. **扫描结果** - 每个合集的视频数量和总时长
2. **Excel文件** - 已生成的Excel框架文件
3. **提示词文件** - 用于AI生成内容的提示词

### 第三步：AI生成内容

1. 读取提示词文件：`D:\study\python\deal_vedio\prompts\{timestamp}_content_prompt.md`
2. 根据提示词生成每个合集的内容介绍和关键字
3. 返回结构化结果

### 第四步：更新Excel

将AI生成的内容写入Excel的K列（内容介绍）和L列（关键字）
