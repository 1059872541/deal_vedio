# 配置文件

## 路径配置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 视频基准目录 | 视频存放的根目录，用户输入 | 无 |
| 输出目录 | Excel输出位置 | D:\VedioRecords\剪辑要求\2026 |
| 模板文件 | Excel格式模板 | D:\VedioRecords\剪辑要求\片单模板.xlsx |
| 提示词目录 | AI提示词存储位置 | D:\study\python\deal_vedio\prompts |

## 输出文件名格式

```
26年波波{月份}月第一批片单.xlsx
```

- 月份：默认当前月份
- 游戏名：固定为"波波"

## 目录结构

```
基准目录\
├── 合集一\成片\{子目录}\*.mp4
├── 合集二\成片\{子目录}\*.mp4
├── 合集三\成片\{子目录}\*.mp4
...
```

## Excel 列说明

| 列 | 说明 | 数据来源 |
|----|------|----------|
| A | 合集名 | 扫描获取 + 命名规则 |
| B | 精彩看点 | 视频标题（第X集 标题） |
| C | 时长（秒） | 视频实际时长 |
| D | 合集时长（秒） | 该合集所有视频时长总和 |
| E | 片头时长（秒） | 固定600 |
| F | 减完片头合集时长（秒） | D列 - E列 |
| G | 主播 | 固定"波波" |
| H | 类别 | 固定"端游" |
| I | 集数 | 该合集视频数量 |
| J | 出品年份 | 固定2026 |
| K | 内容介绍 | AI生成 |
| L | 关键字 | AI生成 |

## 合集命名规则

| 原始文件夹 | 生成合集名 |
|------------|------------|
| 合集六 | 波波之我的世界 通关极光堡垒 |
| 合集七 | 波波之我的世界 征服沼泽强敌-上篇 |
| 合集八 | 波波之我的世界 征服沼泽强敌-下篇 |
| 合集九 | 波波之我的世界 解密黑暗森林与高塔-上篇 |
| 合集十 | 波波之我的世界 解密黑暗森林与高塔-下篇 |

## 视频标题格式

从文件名提取：
- 输入：波波之我的世界 通关极光堡垒 第一集 火焰森林寻路.mp4
- 输出：第一集 火焰森林寻路

## 扫描规则

1. 遍历目标合集列表（如合集六~十）
2. 查找每个合集下的"成片"子目录
3. 在成片目录下找到唯一的子目录（不固定名称）
4. 扫描该子目录下的 .mp4 文件
5. 提取视频标题和时长
