## 📋 第一步：输入信息

你会要求请提供以下信息：

```

   （示例：D:\VedioRecords\工作区\我的世界_202604\合集）

2. 目标合集列表：__________
   （示例：合集六,合集七,合集八,合集九,合集十）
```

## 📋 第二步：扫描视频

AI会自动使用 `get_videos_duration.py` 脚本扫描以下目录结构：

```

基准目录\合集八\成片\唯一子目录\*.mp4

```

脚本会使用 ffprobe 获取每个视频的实际时长，并解析视频标题。

```

| 合集九 | 20 | 8100秒 |

共计：5个合集，100个视频，总时长42720秒
```

## 📋 第四步：生成Excel框架

运行 `get_videos_duration.py` 脚本会自动生成Excel框架，包含以下内容：

**使用固定模板：** `D:\VedioRecords\剪辑要求\片单模板.xlsx`

**写入内容：**

```
✓ 汇总行（A1-G1）：
  - 合集数、总条数、总时长(秒)、总合集时长(秒)、总时长(时)
  - 减完片头总合集时长(秒)、减完片头总时长(时)

✓ 数据行（第5行起）：
  - 合集名（A列）
  - 精彩看点：第X集+标题（B列，每个视频一行）
  - 时长（秒）（C列）
  - 合集时长（秒）（D列）
  - 片头时长（秒）（E列）：固定600
  - 减完片头合集时长（秒）（F列）
  - 主播（G列）：固定"波波"
  - 类别（H列）：固定"端游"
  - 集数（I列）
  - 出品年份（J列）：固定2026
  - 预留：内容介绍（K列）、关键字（L列）待AI填充

✓ 输出文件：
  --output 指定的路径；不传则写在 JSON 同目录，
  文件名 26年{主播}{当前月份}月第一批片单.xlsx
  （脚本不写死任何本机目录，输出到哪完全由调用方决定）
```

**格式说明：**

```
- Row 1 (A-L): 黑色字体 + 黑色边框
- Row 2 (A-L): 黑色字体 + 黑色边框（无填充）
- Row 3: 黑色填充(FF333333) + 合并A3:L3
- Row 4: A-H,K,L列红色加粗，I,J列黑色加粗 + 边框
- 数据行: A,D,E,F,G,H,I,J,K,L列合并（每合集N行），B,C列红色字体 + 边框
```

## 📋 第五步：生成提示词

运行 `generate_sheet.py` 脚本会自动：
1. 扫描视频目录
2. 生成Excel框架
3. 生成AI提示词文件

脚本输出会显示提示词文件路径，如：
`D:\study\python\deal_vedio\prompts\{timestamp}_content_prompt.md`

**此步骤由AI助手自动完成，无需用户手动操作。**

---

## 📋 第六步：AI生成内容

AI助手会自动执行：
1. 读取上一步生成的提示词文件
2. 根据提示词模板和视频标题
3. 为每个合集生成：
   - 内容介绍（20-40字，中文标点，句号结尾）
   - 关键字（4-6个，顿号分隔）
4. 返回结构化结果

**注意**：此步骤由AI助手自动完成，会直接返回生成的内容，无需等待用户进一步输入。

---

## 📋 第七步：写入内容 + 格式化 + 完成

```
1. 将AI生成的内容写入Excel：
   - 内容介绍 → K列
   - 关键字 → L列

2. 应用格式（脚本已自动处理）：
   - 合并单元格（A、D、E、F、G、H、I、J、K、L列，每合集N行）
   - 黑色边框（A-L列所有单元格）
   - 字体颜色（红色内容FFFF0000、黑色表头FF000000）
   - 第3行黑色填充(FF333333)+合并A3:L3

3. 保存到 `--output` 指定的路径（不传则写在 JSON 同目录）

✅ 完成！
```

## 🔧 使用方法

```bash
python generate_sheet.py --base-dir "D:\VedioRecords\工作区\我的世界_202604\合集" --collections "合集九,合集十"
```

脚本会自动递归查找视频目录，无需手动指定完整路径。


## ✨ 新增功能 (v1.2)

### 1. 递归自动查找视频目录
- 输入基准目录 + 合集列表后，脚本会自动递归扫描子目录
- 自动识别包含 "第X集*.mp4" 文件的目录
- 跳过无关目录（图片、素材、缓存等）

### 2. 集数连续性检查
- 自动检测并警告缺失的集数（如缺少第14集）
- 在JSON中记录 `missing_episodes` 字段

### 3. 输出文件名防冲突
- 如果输出文件已存在，自动添加 `_1`, `_2` 等递增后缀
- 例如：`26年波波4月第一批片单_1.xlsx`

### 4. 时长格式修复
- 总时长(时) 和 减完片头总时长(时) 现在正确显示为 `时:分:秒` 格式
- 例如：`4:40:48`

## ❓ 常见问题

### Q1: 如何运行脚本（推荐方式）
A: 
```bash
cd .claude/skills/excel-sheet-generator/scripts

# 方式一：基准目录 + 合集列表（自动递归查找）
python generate_sheet.py --base-dir "D:\VedioRecords\工作区\我的世界_202604\合集" --collections "合集九,合集十"

# 方式二：直接输入完整路径
python generate_sheet.py "D:\视频目录1,D:\视频目录2"
```

### Q2: 可选参数
A:
```
--base-dir 基准目录路径（如 D:\VedioRecords\工作区\我的世界_202604\合集）
--collections 目标合集列表（如 合集九,合集十）
--host 主播名称（默认: 波波）
--category 类别（默认: 端游）
--year 年份（默认: 2026）
--intro 片头时长秒（默认: 600）
--output 输出Excel路径
--no-prompt 跳过提示词生成
```

### Q3: 脚本如何查找视频目录？
A: 脚本会自动递归扫描合集目录下的子目录，寻找包含 "第X集*.mp4" 文件的目录。跳过常见无关目录（图片、素材、缓存等）。

### Q4: 如何只处理部分合集？
A: 使用 --collections 参数：
```bash
python generate_sheet.py --base-dir "D:\合集目录" --collections "合集九,合集十"
```

### Q5: 输出文件名冲突怎么办？
A: 脚本会自动添加递增后缀。如已存在 `26年波波4月第一批片单.xlsx`，会自动生成 `26年波波4月第一批片单_1.xlsx`。

### Q6: 如何检测缺失的集数？
A: 脚本会自动检测集数连续性。如缺少第14集，会输出警告：`警告: 缺少第 14 集`

### Q7: 模板文件路径可以修改吗？
A: 模板文件路径固定为 D:\VedioRecords\剪辑要求\片单模板.xlsx
