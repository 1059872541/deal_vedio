# 视频处理自动化流水线

把「录好的游戏素材」变成「能交付的成片 + 台账」的一条批量生产线。

**入口是一个命令：`vedio`。** 12 个动词覆盖从素材到交付的全过程，
录制、剪辑、审字幕、定篇名这四件事由人做，其余交给程序。

```powershell
vedio run --game 我的世界 --batch 2026-12 --collections 合集一,合集二 `
          --steps export,splice,rename,ledger
```

> 状态：**可用**。字幕、导出、拼接、命名、台账已在真实批次上跑通。

---

## 流水线一眼看完

```
素材 → 匀素材 → 剪辑 → 纠正字幕生成标题 → 生成篇名 → 导出视频 → 分割拼接视频 →  重命名视频标题 → 生成台账
 人    程序     人     程序+人+模型        人        程序       程序             程序        程序+模型
```

| 环节   | 谁做         | 命令             | 产出                             |
| ------ | ------------ | ---------------- | -------------------------------- |
| 素材   | 人           | —                | `合集X/素材/*.mp4、*.mkv` 等视频 |
| 匀素材 | 程序查、人定 | `vedio balance`  | 各合集时长在容差内               |
| 剪辑   | 人（剪映）   | —                | 草稿 + 导出的 `.txt/.srt`        |
| 字幕   | 程序 + 人审  | `vedio subtitle` | `*_corrected.srt`                |
| 篇名   | 模型提、人拍 | `vedio series`   | `标题.md` 的副标题               |
| 导出   | 程序         | `vedio export`   | `剪辑/*.mp4`                     |
| 拼接   | 程序         | `vedio splice`   | `成片/*.mp4`                     |
| 命名   | 程序         | `vedio rename`   | 按标题改好名                     |
| 台账   | 程序 + 模型  | `vedio ledger`   | `26年…片单.xlsx`                 |

每个环节**做什么、预期是什么、产物长什么样** → [docs/流程.md](docs/流程.md)

## 三步开始

```powershell
# 1. 装环境（Python 3.12+ / ffmpeg / 剪映）
#    详见 docs/安装与配置.md

# 2. 填两个配置文件（都不进 git）
#    conf/本机.yaml    —— 工作区在哪、ffmpeg 在哪
#    conf/agent.yaml   —— DeepSeek 的 key / 模型 / 额度

# 3. 建第一批，看状态
vedio init --game 我的世界 --batch 2026-12 --collections 2 --host 波波
vedio status --game 我的世界 --batch 2026-12
```

环境配置的逐步引导 → [docs/安装与配置.md](docs/安装与配置.md)

## 仓库里有什么

| 路径                    | 是什么                                             |
| ----------------------- | -------------------------------------------------- |
| `src/vedio/`            | **命令行内核**：12 个动词、从文件推状态、跑 ffmpeg |
| `src/deal_video_agent/` | 字幕纠错 agent（LangGraph）+ **全部提示词**        |
| `src/jianying_export/`  | 剪映 GUI 自动化（只用于导出）                      |
| `src/util/`             | 零散工具（匀素材底层、时长探测等）                 |
| `conf/`                 | 规则与配置（默认规则、游戏规则、知识库）           |
| `docs/`                 | 文档                                               |
| `tests/`                | 634 个单元测试                                     |
| `research/`             | 研究笔记，**不进 git**，换机器就没有               |

设计原则：**文件系统即真相**（没有数据库）；**内核不知道模型存在也能跑**（除字幕那一段）。
